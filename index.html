              Sync & Team

              This app works entirely offline and keeps your projects in this browser. Connecting a Supabase project adds a copy on a server you own, so the same data reaches your other devices and teammates can be given access.

              1 · Connect a Supabase project

              Create a free project at supabase.com, run supabase/schema.sql from this repository in its SQL editor, then paste the project URL and anon key from Project Settings → API. Both are stored in this browser only. The anon key is meant to be public — row level security is what protects your data.

              2 · Sign in

              We email you a sign-in link — there is no password to choose or store. Open it on every device you want to keep in sync.
